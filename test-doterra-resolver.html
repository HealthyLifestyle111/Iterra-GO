What Was Fixed?

  • Previous Issue: The resolver was treating dummy/display names like product slugs, causing broken or mis-routed links.
  • Solution: Implemented direct-or-search logic:
    • Real doTERRA slugs (from mapping table) → Direct to /p/<slug>
    • Dummy/generic labels (display names, human phrases) → Redirect to doTERRA search
    • No more scraping HTML or guessing - deterministic routing based on slug validation
  • How It Works:
    • Maintains small "known direct slug" map (DIRECT_SLUGS from DOTERRA_SLUG_FIX)
    • Detects dummy names: spaces, human phrases, anything not in slug format
    • Uses isLikelySlug() function to validate slug format (lowercase, dashes, no spaces)
  • Result: Oils and mapped products go to exact product pages, dummy names go to search results (always relevant, never dead links)
