What Was Fixed?

  • Backend Issue: The resolver was scraping doTERRA HTML and extracting the FIRST product link it found, which was always the "Foundational Wellness Bundle" promo that appears on every page.
  • Solution: Replaced HTML scraping with a deterministic slug mapping table and smart redirect logic:
    • Known products → direct to product page
    • Unknown items → search results (never defaults to one product)
  • Frontend Option: Can use doterraUrl() for direct links or doterraGoUrl() for backend-resolved links with associate attribution.
